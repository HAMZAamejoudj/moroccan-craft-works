# Moroccan Craft Works

Authentic Moroccan Handicrafts, bespoke custom manufacturing, and global freight export platform.

## Overview

Moroccan Craft Works connects international interior designers, luxury hospitality brands, boutique retailers, and wholesalers with generational artisan cooperatives across Morocco (Fes, Marrakech, High Atlas, Safi, and Essaouira).

### Key Features
- **Curated Craft Collections**:
  - Hand-knotted Berber rugs (Beni Ourain, Azilal, Boujad, Kilim)
  - Architectural zellige tiles, fountains, and mosaic tables
  - Pierced brass lanterns, chandeliers, and copperware
  - Handcrafted ceramics, pottery, and glazed tableware
  - Full-grain Moroccan leather poufs, bags, and bespoke upholstery
  - Palm leaf & raffia basketry, woven lighting, and storage
  - Hand-carved Thuya wood boxes, burl tables, and sculptural furniture
  - Hand-spun wool pom-pom blankets, throws, and cactus silk cushions
- **B2B Sourcing & Export Services**:
  - Custom Manufacturing & Private Label (CNC brass hallmarks, debossing, damask labels)
  - Wholesale Guild Supply & Multi-Category Freight Consolidation
  - ISPM-15 Certified Export Wooden Crating
  - Tracked Worldwide Freight (DHL Express & FCL/LCL Ocean)
  - Duty-Free Documentation (EUR.1, Certificates of Origin, Fumigation)
- **Interactive Inquiries & Trade Quotes**:
  - Direct WhatsApp Guild concierge integration
  - Interactive multi-parameter quote request modal
  - Responsive catalog filtering with search and MOQ details

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations / Components**: React, Tailwind

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment variables**:
   Copy `.env.local.example` to `.env.local`:
   ```bash
   cp .env.local.example .env.local
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

4. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```
